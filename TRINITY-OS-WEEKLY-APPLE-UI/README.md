# TRINITY OS Weekly Plan Apple UI

현재 main 기준 Weekly 목표 영역과 Weekly Execution을 정돈된 리스트형 UI로 변경합니다.

- 큰 목표 카드/상시 입력 폼 제거
- 요약 strip
- 상태 badge + 더보기 메뉴
- 목표 추가/수정 우측 sheet
- Daily Plan 직접 연결
- 설정에서 지정한 과목별 색상을 그대로 사용
- Weekly Execution 표 compact styling
- iPad / mobile / dark mode 대응

## 적용
TRINITY-OS 루트에서:

```bash
bash TRINITY-OS-WEEKLY-APPLE-UI/APPLY_PATCH.sh
```
